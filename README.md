# MY Notification

Уведомления для рабочего стола Material You на i3.

## Назначение системных звуков

| Событие | Что сообщает | Как должно звучать |
| --- | --- | --- |
| Сообщение и почта | Появилось что-то новое, можно посмотреть, когда удобно | Мягкая «Колыбельная» с чистым первым щипком, лёгким подъёмом и спокойным затуханием. Около 350–520 мс. |
| Изменение громкости | Нажатие сработало, слышен текущий уровень | Один короткий приглушённый щипок, около 85 мс. Без второй ноты, чтобы серия нажатий оставалась разборчивой. |
| Подключение и информационный диалог | Устройство готово или действие завершилось | Быстрый уверенный подъём двумя нотами. Короче уведомления, с более сухим окончанием. |
| Отключение | Устройство больше недоступно | Короткий мягкий спад. Небольшая громкость, чтобы обычное отключение воспринималось спокойно. |
| Вопрос, предупреждение и запрос внимания | Событие стоит заметить сейчас | Два коротких щипка на одной высоте с отчётливой паузой. Повтор выделяет сигнал среди мелодических звуков. |
| Ошибка | Действие не удалось, нужно проверить результат | Две ноты ниже по регистру, с заметным нисходящим интервалом и коротким окончанием. |

Частые сигналы занимают меньше времени и требуют меньше внимания. Тишина сохраняется для обычной навигации, служебных плашек и уведомлений, скрытых режимом «Не беспокоить». [Рекомендации команды Pixel](https://design.google/library/creating-consistency-one-pixel-at-a-time) · [Good Vibrations, Google Design](https://design.google/library/ux-sound-haptic-material-design)

## Колыбельная

Основной сигнал — две ноты калимбы, до и ля. У атаки убраны резкие верхние частоты, а вторая нота звучит тише и дольше затихает. [Готовый WAV](audio/lullaby.wav) · [Исходная запись](audio/source/kalimba.mp3)

### Новые варианты

| Сигнал | Как устроен | WAV |
| --- | --- | --- |
| Рассвет | До → ми. Два раздельных щипка с лёгким подъёмом. 431 мс. | [Послушать](audio/lullaby-dawn.wav) |
| Качание | До → ми → до. Последняя нота мягче и возвращает фразу на место. 502 мс. | [Послушать](audio/lullaby-sway.wav) |
| Огонёк | Соль → до, к последней ноте присоединяется тихое ми. 450 мс. | [Послушать](audio/lullaby-glow.wav) |

В прежнем сигнале доля полосы 2,5–6 кГц в первых 60 мс была на 3,7 дБ ниже, чем в записи щипка. У сигнала ошибки относительная доля этой полосы ещё на 1,5 дБ ниже, а обе фразы идут вниз. Эта комбинация могла делать прежнюю версию глухой и похожей на ошибку. Для новых фраз использованы отдельные записи трёх нот. В полосе атаки больше энергии, а громкость самого энергичного участка отличается между вариантами на 0,9 дБ.

В «Параметры → Уведомления» можно выбрать сигнал, послушать его и показать тестовую карточку. «Из звуковой темы» берёт сигнал из раздела «Звук», где доступны «Колыбельная» и стандартная тема Freedesktop. Переключатели уведомлений и системных событий действуют независимо.

Тема добавляет свои звуки для сообщений, изменения громкости, событий подключения и отключения, запросов внимания, предупреждений и ошибок. Приложения воспроизводят их по именам событий Freedesktop. Для остальных событий используется наследование Freedesktop. [Формат звуковых тем](https://specifications.freedesktop.org/sound-theme/latest/)

Тёмная тема использует снимок синей палитры m3. Карточка использует `surfaceContainerHigh`, область иконки — `primaryContainer`, текст — `onSurface` и `onSurfaceVariant`. ## Что делает звуки Pixel узнаваемыми

**Materia** — тема Freedesktop на основе библиотеки Google Material Sound, опубликованная до Material 3. В сборке тема сопоставляет входящее сообщение `message-new-instant` с `notification_high-intensity`, а диалог с вопросом — с `notification_simple-01`. Поэтому при оценке обычного уведомления я сравнил оба файла и дополнительно взял штатные сигналы Pixel. [Materia Sound Theme](https://github.com/nana-4/materia-sound-theme/tree/10d30e9a01af4dec6a9cf94317c9536fec5a24f4) · [Карта событий Materia](https://github.com/nana-4/materia-sound-theme/blob/10d30e9a01af4dec6a9cf94317c9536fec5a24f4/material_product_sounds/meson.build)

Команда Pixel записывает бытовые звуки и использует их вместе с музыкальными и цифровыми тембрами. Примеры Google включают звук закрывающегося ящика и звук риса, высыпаемого на сковороду. Для уведомлений дизайнеры рекомендуют короткий, различимый сигнал, который легко услышать много раз за день. Попкорн послужил образом для музыкального жеста `Popcorn`. [Процесс команды Pixel](https://blog.google/products-and-platforms/devices/pixel/google-pixel-sound-design/) · [Дизайн звуков первого Pixel](https://design.google/library/creating-consistency-one-pixel-at-a-time) · [Интервью с Конором О’Салливаном](https://design.google/library/google-pixel-sound-design-ux-conor-osullivan)

Для запуска Material 3 и Pixel 6 в 2021 году Google создал коллекцию Material Adventures. В ней команда шире экспериментировала с текстурами и жанрами. В той же статье дизайнеры описывают, как уменьшают заметность звуков по мере того, как событие становится привычнее и чаще. [Good Vibrations, Google Design](https://design.google/library/ux-sound-haptic-material-design)

| Референс | Длина файла | Активное звучание | Наблюдение |
| --- | ---: | ---: | --- |
| Materia Simple 01 | 817 мс | ≈200 мс | Один компактный акцент |
| Materia High Intensity | 1 289 мс | ≈560 мс | Более длинный спад после акцента |
| Pixel Popcorn | 1 589 мс | ≈590 мс | Два акцента примерно на 50 и 140 мс, второй светлее |
| Pixel Eureka | 1 102 мс | ≈645 мс | Два акцента примерно на 45 и 150 мс, у второго выше главный спектральный пик |

Измерения сделаны на декодированных монофайлах. Активное звучание — от первого до последнего 5-мс окна с RMS выше −35 дБ относительно самого громкого окна файла. Моменты акцентов оценены по росту энергии. Файлы Pixel взяты из архива системных звуков для анализа. [Архив Pixel Sounds](https://3.onj.me/phonetones/unzipped/Google/%21%20Google%20Sounds/Pixel%20Sounds/notifications/)

В новых вариантах я сохранил атаку живой записи, из неё же сделал вторую, более тихую ноту через 82–112 мс и дал ей плавно затихнуть. Первый импульс звучит примерно через 40 мс после начала анимации карточки. Калимба поднимается на терцию, пианино спускается на тон, а нейлоновая струна отвечает квинтой. Это даёт общую форму и три разных контура. [Записи и обработка](audio/CREDITS.md)

## Flake

Послушать звук отдельно в графической сессии:

```sh
nix run github:Kostr2007/MY-notification
nix run github:Kostr2007/MY-notification -- lullaby-dawn
nix run github:Kostr2007/MY-notification -- lullaby-sway
nix run github:Kostr2007/MY-notification -- lullaby-glow
nix run github:Kostr2007/MY-notification -- kalimba
nix run github:Kostr2007/MY-notification -- piano
nix run github:Kostr2007/MY-notification -- nylon
```

Для конфигурации m3 на i3 есть [патч подключения](nix/examples/m3-i3.patch). Он добавляет input в системный flake, передаёт его в Home Manager и ставит звуковую тему в XDG. Функция `my-notification.lib.withM3 pkgs m3Base` добавляет элементы выбора в «Параметры» и обновляет шаблоны Dunst, picom и XSettings. Во время активации штатный `m3 render` заново генерирует конфиги из текущей палитры и пользовательских настроек. Picom использует пружину, приближенную к макету, с системным масштабом анимаций.

В рабочей копии конфигурации NixOS проверьте, затем примените патч:

```sh
patch --dry-run -p1 < /путь/к/MY-notification/nix/examples/m3-i3.patch
patch -p1 < /путь/к/MY-notification/nix/examples/m3-i3.patch
nix flake lock
```

После активации этой конфигурации можно проверить связку в i3:

```sh
notify-send -a 'Система' -i drive-harddisk 'Резервная копия готова' 'Изменения сохранены на внешнем диске.'
```

Dunst запускает скрипт при показе уведомлений обычной срочности. Скрипт учитывает «Не беспокоить» и пропускает служебные уведомления m3 и OSD.

## Редактирование звука

[ForgeSound Engine](https://github.com/Kostr2007/ForgeSound-Engine) позволяет работать с семплами, слоями и огибающими. Для сборки WAV используется Python и FFmpeg из dev shell:

```sh
nix develop -c python3 tools/render-sound.py all
```

Для сравнения вариантов скрипт выдаёт JSON с длительностью, началом атаки, концом активного участка, пиковым уровнем, максимальным RMS за 50 мс и относительной энергией полосы 2,5–6 кГц в первые 60 мс атаки. Атака и конец оцениваются по окнам RMS по 5 мс относительно самого громкого окна, с порогами −30 и −35 дБ соответственно.

```sh
nix develop -c python3 tools/render-sound.py --analyze audio/lullaby.wav audio/error.wav audio/lullaby-*.wav
```
